# DataFrameReporter

Класс для первичной диагностики датафреймов pandas. Отчёт показывает размер таблицы, количество и долю дубликатов, сводную статистику, количество и долю пропусков.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Поместите файл `payments.csv` в папку `data`, затем выполните команду

```bash
python3 main.py
```
